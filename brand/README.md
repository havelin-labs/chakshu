# Brand

Chakshu (चक्षु) means "the eye". The mark is an eye on an orange-to-violet tile; the dot in the iris is the glint of something noticed.

| File | Use |
|---|---|
| `logo.svg` | Horizontal lockup for READMEs, docs and slides |
| `../frontend/public/favicon.svg` | The square icon: favicon, app header, avatars |

## Colors

| Name | Hex | Use |
|---|---|---|
| White | `#FFFFFF` | Backgrounds |
| Sunset orange | `#FF5841` | Gradient start, highlights, charts. Not behind text: white on orange is only 3.1:1. |
| Red-violet | `#C53678` | Primary buttons, links, focus rings. White text on it is 5.0:1. |
| Red-violet (dark mode) | `#E35D97` | Primary in dark mode, with dark text |

The gradient runs orange to violet at 110°. The portal's tokens live in `frontend/src/index.css` (`--brand-orange`, `--brand-violet`, `bg-brand-gradient`, `text-brand-gradient`).

## Don'ts

- Don't recolor the mark or put it on a busy photo.
- Don't stretch it; keep the tile square with its rounded corners.
- The wordmark is lowercase.
