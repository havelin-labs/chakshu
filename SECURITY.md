# Security

Please don't report security problems in public issues.

Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). We aim to reply within three working days and will credit you in the release notes unless you'd rather we didn't.

Chakshu reads code from pull requests, some of which may come from people you don't trust. If you find a way for pull request content to make a review do something beyond reading the code it was given, we especially want to hear about it.
